# Super Тёпа

Песочница, максимально близкая к Minecraft Java Edition по графике и физике. Главный герой — Тёпа, коричневая собачка с жёлтыми крыльями-бабочками.
Написана с нуля на Three.js (r170), без сборщика и без чужих ассетов: все текстуры рисуются кодом.

## Запуск
Двойной клик по `start.command`: откроется браузер на http://localhost:8778.
Или вручную: `python3 -m http.server 8778` в этой папке.

## Что уже есть (v0.1)
- Бесконечный мир из чанков 16×16×256: равнины, лес, пустыня, снег, горы, пляжи, океаны, пещеры, уголь и железо, дубы, берёзы, трава, цветы.
- Графика как в MC: текстуры 16×16 без сглаживания, освещение уровнями 0–15 (небо и блоки), smooth lighting с AO, затенение граней, туман, квадратные солнце и луна, звёзды, облака, смена дня и ночи (20 минут).
- Физика 1-в-1 с MC, проверена тестом: ходьба 4,317 м/с, бег 5,612, присед 1,295, прыжок 1,2522 блока, полёт 10,89 / 21,78, лёд, вода, шаг на ступеньку 0,6, присед не даёт упасть с края.
- Ломание и установка блоков, 33 блока, хотбар, инвентарь (E), взятие блока средней кнопкой, частицы.
- Тёпа: модель в стиле мобов MC, анимации ходьбы, полёта (двойной пробел), хвост, уши, крылья. Вид от 3-го лица — F5 или V.
- Сохранение мира в браузере (localStorage), настройки (дальность, FOV, чувствительность, покачивание).

## Структура
```
index.html, style.css     страница и интерфейс
src/main.js               цикл игры, управление, камера, сохранение
src/player.js             физика (порт из MC: гравитация 0.08, трение 0.546/0.91, прыжок 0.42…)
src/world.js              чанки, правки, освещение (flood fill)
src/worldgen.js           генерация мира
src/mesher.js             геометрия чанков, AO, smooth lighting
src/renderer.js           шейдер освещения, загрузка и выгрузка чанков
src/textures.js           пиксельные текстуры блоков
src/blocks.js             список блоков
src/sky.js                небо, солнце, луна, облака
src/tepa.js               модель и анимация Тёпы
src/particles.js, ui.js   частицы, интерфейс
vendor/three.module.js    Three.js r170
```
В консоли браузера доступен объект `game` для отладки.
